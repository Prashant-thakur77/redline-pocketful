# Failed experiments

What we tried, what broke, and what we changed. FACTORY.md quotes this.

| # | Tried | What happened | Fix |
|---|---|---|---|
| 1 | Model ids `claude-opus-5-5` / `claude-sonnet-5-5` in mandates | Claude Code CLI: `unrecognized_model` | Use the ids the CLI resolves: `claude-opus-5`, `claude-sonnet-5` (preflight `--probe-models` now catches this) |
| 2 | "Split long handoffs" in every mandate | Our scanner flagged `split` (a product noun in one track) | Reworded to "break long handoffs"; scanner runs in preflight and in the test suite |
| 3 | Scanning whole `.py` files for track nouns | `collections.Counter` and `str.split` flagged as product nouns | Scan only comments and strings in Python (where track detail would leak) |
| 4 | Fake API key literal in a factory test | The task harness's credential scan flagged it — would fail `harness check` in the result repo | Build fake keys at runtime; credential scan added to the phase review |
| 5 | Local rehearsal with real model seats (`claude -p`, `codex exec`, approvals bypassed) | Refused by the development session's safety policy: no unsupervised agents launched from it | Scripted plumbing rehearsal locally (real gates, ledger, reports); model rehearsal moved to Band Desktop |
| 6 | UI gate on a fixture page with default inputs | Gate 7 failed: input 21 px tall (< 24 px target) | Kept the gate strict; fixed the page. Same bar applies to the band's UI |
| 7 | Groq free tier for @adversary (gpt-oss-120b, qwen3.8-27b) through OpenCode | Every request rejected: free tier allows 7–8k tokens/minute, one OpenCode request is ~11k | Gemma 4 31B (open weights) via the Gemini API, local Ollama as fallback |
| 8 | Passing the Claude seat's tool allowlist as a CLI flag | The BAND SDK owns `--allowedTools` and refuses it | Allowlist moved to the result repo's `.claude/settings.json`, loaded with `setting_sources=("project",)` |
| 9 | Gemini 3.5 Flash live probe | HTTP 503 (overloaded) on first call | Probes and seats retry with backoff; each Gemini seat falls back to the other Gemini model |
| 10 | Verifier scope check from the seed tag | One reverted violation kept the range red forever | Check from the last GO; a path restored to its pre-violation content no longer counts (the BLOCK stays in the ledger) |
| 11 | Test-count ratchet per stage | Removing a test right after copy-forward was invisible (new stage had no history) | Ratchet compares against the highest count of this or any earlier stage |
| 12 | Rejection "recovered" judged by ledger file order | The plumbing rehearsal showed a BREACH as unrecovered: room events are ingested after the run, so file order is not time order | Recovery is judged by timestamp; regression test proves it |
| 13 | Pasting the run commands as one block into a terminal | When the band was stopped, the terminal went on to run `make dispatch-toy`: two dispatches, two planners on one repo | `factory.dispatch` refuses a second send for the same run within 12 h; the band runs detached (`make band DETACH=1`) |
| 14 | Restarting the band while old rooms still held messages | Restarted seats rejoined every room they belonged to and took turns on stale dispatches | Smoke rooms delete themselves; `factory.smoke --close` removes stale rooms before a new run (preflight checklist) |
| 15 | Gemini free tier for the test and verifier seats | `quota exceeded … free_tier_requests, limit: 20` per model per day; the seat stalled on its first turns | Codex `gpt-5.5` on the ChatGPT login for both seats; preflight probes now cost one call each |
| 16 | Local `qwen2.5:7b` as the adversary fallback | Calls tools in OpenCode but wrote outside the working directory (auto-rejected) | Kept as last resort only; Gemma 4 31B stays primary |
| 17 | Codex seats in a workspace-write sandbox | `.git` stays read-only, so Redline could not commit; the Planner committed its tests under Redline's name, and every band commit showed the human as committer | `.git` named as a writable root; each seat process gets its own author and committer identity; the scope check flags committer ≠ author; mandates forbid committing under another seat's name |
| 18 | Codex on the ChatGPT login for the test and verifier seats | `You have hit your usage limit … try again at Nov 3rd` on the first turn; also the Codex adapter refuses one workspace shared by two rooms | Gemma 4 (open weights) via OpenCode for the three verification seats; Featherless next |
| 19 | Gemma 4 free tier for three seats | `free_tier_input_token_count, limit: 16000` per minute; one agent request with context exceeds it | All seats on Claude Code (different models per role) until Featherless; documented in Limits |
| 20 | Code review of the factory by a separate agent | 14 findings: the verifier mandate would check out commits in the shared tree, a torn ledger line would crash every later gate, gate 6 passed when the baseline was red, verdicts double-counted, gates crashed on hook errors | Gates and `serve` build `--commit` in a private worktree; mandates forbid checkout; ledger repairs a torn tail; gate 6 needs a green baseline; every gate failure is recorded instead of crashing |
| 21 | Gate 5 sharing the service gate 4 had just stormed | Found by the Planner seat during the toy rehearsal: earlier-stage tests that assume a fresh service false-fail | Gate 5 starts its own service; the storm runs last among shared gates; regression test added |
| 22 | Claude Haiku as the verifier | Issued a BLOCK the mandate reserves for weakened tests, then a GO with gate 2 still red; once ended a turn in plain text | Verifier on Opus; `factory.record` refuses a GO the gate results do not support; the report states how many GOs are backed; every mandate says replies go through the send-message tool |
| 23 | Default (high) effort on every Claude seat | Toy stage 1 cost $700.94 list-price-equivalent over 93 turns in about an hour (builder $310 over 36 turns), a fast drain on a subscription allowance | `effort: medium` for the builder and adversary; judgment seats stay high; spend per seat is now measured from the seat logs |
| 24 | Regex mutants on every line | The Planner traced half the gate-6 survivors in toy stage 1 to mutants inside a trailing comment and a docstring: unkillable, so the score was understated | Gate 6 skips comments and string literals (tokenizer for Python, `//` for others); the Planner's rule for genuinely equivalent mutants is recorded in the run |
| 25 | Courtesy copies ("copy @planner", "FYI") in handoffs | Every mention wakes a seat for a full turn; toy stage 1 used 146 turns in 80 minutes | Mandates: mention only the seats that must act now; the planner follows progress through its status file and the ledger |
| 26 | Per-item gate 2 against the whole stage's tests (official run) | Found by the Verifier seat: tests are written for the entire stage first, so gate 2 stays red until the last item lands and the ledger-enforced GO refuses every early item | `--req R-…` scopes gate 2 to an item's own requirements (tests name their ids); stage close still runs the full suite. Shipped after the run; the run itself closed items on content and made the stage-close GO binding |
| 27 | Governor counting every rejection as an attempt (official run) | Found by the Verifier seat: repeated re-checks of the same commit used up an item's attempts | One attempt per rejected commit |
| 28 | Watchdog asking the sender to resend after a turn ended without a send (official run) | Most such turns were seats correctly deciding they had nothing to add; the resend requests only cost turns | Watchdog acts on usage limits and hung runtimes only |
| 29 | Restarting the watchdog with a full log rescan (official run) | It read the old, already-fixed planner hang as live and restarted the planner mid-turn ("Internal error" in the room) | Hang detection only counts log lines written after the watchdog starts |
| 30 | Counting every red scope finding against GO (official run) | The stage-1 close sat on eight clean gates: the Adversary's one-for-one test replacement (a deletion the Planner had ruled legitimate) kept the scope gate red, and the ledger refused GO | A scope finding that only reports deleted tests is for the Verifier to rule on; any other scope finding still blocks GO |
| 31 | Trusting a seat's commit to mean the room heard about it (official run) | The Verifier committed its stage-1 close verdict, its send never landed, and the room sat silent for 50 minutes | The watchdog asks a seat whose newest commit has gone unreported for 15 minutes to post the result |
| 32 | Treating a quiet room as a stalled one (official run) | The new unreported-commit check nudged twice while the test seat was in a 20-minute turn writing the stage-2 suite; each nudge cost a turn | No nudge while any seat is mid-turn (its log shows a query started and not yet completed) |
| 33 | Letting seats run gate suites as background commands (official run) | A seat started the run in the background and ended its turn with no reply; the turn that resumed when the run finished was outside the BAND runtime, so its report went nowhere. Three N2-1 reports were lost and the room sat silent for 45 minutes | Seats run with background tasks off and a two-hour command limit, so a turn ends with its report |
| 34 | A fixed 900 s limit on the spec-test run (official run) | Stage 2's suite, with browser tests waiting on screens not yet built, ran past it; pytest wrote no report and gate 2 called it a removed test | A timeout is reported as a timeout; the limit is 2400 s and settable with `--timeout` |
| 35 | A one-hour turn limit with background commands off (official run) | The builder's build-and-gate turn on N2-4 hit the limit and was cut off mid-work (its commit had landed; the report had not) | Claude turns may run three hours, longer than the two-hour command limit |
| 36 | Running gate 6's unmutated baseline under the 180 s per-mutant limit (official run) | Stage 2's suite takes ~250 s, so every stage-2 close read 'baseline not green'; a timed-out mutant would also have counted as killed | The baseline gets the suite limit, a mutant twice the baseline's time, and a timed-out mutant is reported apart from kills |
| 37 | Planner mandate: 'final report when every stage is closed or the budget stops the run' (official run) | The planner read stage 2's spent clock as the end of the run, posted its final report and stood the band down; 2 h 15 min idle before the operator noticed | A stage cap ends that stage, never the run; the operator clarified the mandate (11a52eb) and posted one disclosed message to resume |
| 38 | Relying on BAND's reconnect after a host network outage (official run) | The laptop lost DNS three times on 5 Oct (07:30-09:35, 12:54-15:38, 17:44-17:54); turns running at the time failed and nothing resumed them, so the band sat idle | The watchdog restarts every seat when a seat reconnects after an outage, and asks seats to post commits the outage swallowed |
| 39 | Relying on each gate's `finally` to remove its containers (official run) | Seats killed by restarts, turn limits and outages left 18 gate containers running for up to 10 h, slowing later gate runs on a 2-vCPU budget | Prune `redline-gate` containers older than the longest gate run before a close; candidate for a gate-run preflight |
